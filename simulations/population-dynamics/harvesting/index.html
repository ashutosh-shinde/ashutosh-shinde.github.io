The theory, in short

  • Harvest on top of growth. Without harvest the population grows logistically; the harvest H(N) is subtracted: dN/dt = rm N(1 − N/K) − H(N).
  • Holling types. Type 0: a fixed catch c. Type I: a fixed share h0N. Type II: h0N/(N0 + N), which saturates at h0 (harvesters can only take so much). Type III: h0Nθ/(N0θ + Nθ), slow at low density (harvesters switch to other prey), with shape θ.
  • Rescaling. For II and III, y = N/N0, k = K/N0, h = h0/(rmN0), t′ = rmt give dy/dt′ = y(1 − y/k) − h yθ/(1 + yθ): only k, h, θ matter.
  • Equilibria are where growth equals harvest; one is stable when harvest overtakes growth there (f ′(u*) < 0, linear stability test).
  • Fold (saddle-node) bifurcations. When the harvest rises past a critical value, a stable and an unstable equilibrium meet and vanish: the population collapses. Type 0: cc = rm/4. Type II: hc = (k + 1)²/(4k) for k > 1; for k ≤ 1 there is no fold, the population fades out at h = 1.
  • Hysteresis. After a collapse, lowering the harvest back to hc is not enough: Type II needs h < 1, Type III needs the lower fold. Type 0 never recovers (extinction is absorbing).
  • The shape θ. θ > 1: extinction is impossible (f ′(0) = 1), but the population can be pushed down to a low refuge. θ < 1: the per-head harvest grows without limit as N → 0, so small populations are always harvested out. θ = 0: a constant harvest again.
  • Critical slowing down. Near a fold, f ′(u*) → 0, so the relaxation time τ = 1/|f ′(u*)| grows without limit: the population recovers from small pushes ever more slowly, an early warning of collapse.
  • Maximum sustainable yield for Types 0 and I is rm/4, at x = ½ (half of K).
